# VetCare

Demonstração do sistema de gestão de clínica veterinária, feita só com HTML, CSS e JavaScript.
Estilo arquitetural: monolito modular.

## Como rodar
No terminal, dentro desta pasta: `python3 -m http.server 8000`
Depois abra http://localhost:8000 no navegador.
